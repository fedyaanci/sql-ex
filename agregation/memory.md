## Фильтрация
Основные моменты

distinct Убирает полные дубликаты строк из результата.
```sql 
SELECT DISTINCT(*) -- ПОПАДУТСЯ ВСЕ УНИКАЛЬНЫЕ СТРОКИ

SELECT DISTINCT COLUMN --  попадутся не null строки

DISTINCT col1, col2 --проверяет уникальность пары значений, а не каждого столбца по отдельности.
```
